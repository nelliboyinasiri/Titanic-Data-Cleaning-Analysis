# Titanic Data Cleaning & Passenger Analysis

## Objective
Analyze passenger survival trends using the Titanic dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Tasks
- Data Cleaning
- Missing Values
- Duplicates
- Outlier Detection
- Filtering
- GroupBy
- Data Visualization

## Conclusion
This project analyzes passenger survival trends using data cleaning, statistics, filtering, grouping, and visualization.
